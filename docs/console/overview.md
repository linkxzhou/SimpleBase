# 控制台概览

管理端是 Vue 3 SPA（`ui/`），生产构建嵌入 Go 二进制，由后端做 history 模式回退。

## 信息架构

| 入口 | 路径 | 说明 |
| --- | --- | --- |
| 监控大盘 | `/` | 配额与数据库概览 |
| 数据库管理 | `/databases` | 库生命周期 + SQL 工作台 + 集合/文档 |
| S3 对象存储 | `/s3` | 项目对象浏览与上传 |
| Cloud Agent | `/agents` | 只读工具 Agent |
| 日志 | `/logs` | 日志查看（能力以页面提示为准） |
| 设置 | `/settings` | 主题、模型相关配置 |
| 使用文档 | `/docs` | **独立文档壳**，不使用控制台侧栏 |

## 全局项目

右上角项目切换器选择或创建当前项目。数据库、S3、Agent 等页在未选项目时会提示创建，而不是静默空白。

文档路由 `/docs` 不进入该项目作用域。

## 连接

右上角齿轮打开 API Key 抽屉。401 时角标提示 Key 无效。Mock 模式顶栏显示「Mock 数据」。

## 文档站交互

- 左侧：模块（入门 / 控制台 / 运维 / API / 参考）与页面列表，来源 `docs/_meta.json`
- 中间：Markdown 正文
- 桌面右侧：当前页标题目录
- 顶栏：返回控制台
